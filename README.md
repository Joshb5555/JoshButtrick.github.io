# Joshua Buttrick portfolio

## Add a project
1. Copy `projects/template.html` to `projects/my-project.html` and edit the text.
2. Add a card to `index.html` and `projects/index.html`, copying an existing `<a class="card">` block and changing the link, title, and image name.
3. Photos go in `img/`, videos (mp4) in `video/`:
   - card thumbnail: `img/my-project.jpg` (4:3 works best)
   - gallery images: `img/my-project-1.jpg`, `-2.jpg`, `-3.jpg`
   Missing images are hidden automatically.

## Deploy
Upload everything to a repo named `<username>.github.io`, then enable Pages (Settings, Pages, main branch).
